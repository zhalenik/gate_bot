Два способа подключения YCLIENTS

Учётная запись YCLIENTS. При регистрации на сайте укажите ID филиала. В этой карточке войдите с логином и паролем обычного пользователя YCLIENTS. Установка приложения из маркетплейса не требуется. После проверки прав здесь появятся имя пользователя и статус связи; пароль не сохраняется.

Приложение YCLIENTS Marketplace. В карточке GateBot нажмите «Подключить», выберите филиал и перейдите в GateBot. ID филиала, логин и пароль YCLIENTS вводить не нужно. Создайте аккаунт GateBot или войдите в существующий. Новому филиалу сначала требуется подтверждение суперадминистратора; затем снова начните подключение из карточки и завершите его в течение часа. Для этого способа используется системный пользователь приложения, а форма ручной авторизации недоступна.

В обоих случаях нужны чтение записей всех сотрудников, доступ к данным клиента и телефонам в журнале. Доступ ко всей клиентской базе и email проверяется отдельно. Если для уведомлений выбран YCLIENTS, пользователю дополнительно нужны права на рассылку. Изменение записей, удаление и финансы не используются.

Сообщения через ChatPush или YCLIENTS

В блоке «Сообщения клиентам» выберите способ доставки. ChatPush напрямую использует токен аккаунта и номер телефона. Рассылка YCLIENTS использует подключение филиала и ID его клиента; тип доставки определяется сервисом рассылки, настроенным в YCLIENTS.

Автоматический выбор использует подключённый ChatPush, иначе YCLIENTS. Клиент разрешает общий канал «Мессенджеры (сообщение от администратора)». Для гостя без ID YCLIENTS доступна прямая отправка через подключённый ChatPush. Сохранение настройки не отправляет пробных сообщений.
