Создать модуль sim800c.py 
    Разместить в модуле функцию-заглушку open_gate(telephone).
    Создать умную очередь звонков:
        Если поступило несколько запросов дозвона на один и тот же номер, то выполнять только один (удалить из очереди остальные запросы на этот номер)
        Если запрос находится в очереди дольше порогового значения call_queue_timeout = 40 секунд то этот звонок не выполняем - когда модуль sim800 долго "не отвечал" например. Все запросы старее считаем неактуальными
        Если в очереди больше max_calls_in_queue = 4, то возвращаем ошибку ("очередь команд переполнена" в лог) (клиент должен получить сообщение в status message или в боте "ошибка связи. повторите попытку позже.")
        все параметры держим в конфиг.пу
