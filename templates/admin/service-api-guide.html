Управление токенами

Подключение

Отправляйте запросы со своего сервера по HTTPS. Базовый путь /api/v1. Передавайте токен в заголовке Authorization: Bearer <токен>. Для POST укажите Content-Type: application/json.

Отправить код

Тело POST содержит один строковый параметр {"phone":"<номер с кодом страны>"}. При успехе сервер вернёт HTTP 200 и JSON-строку из шести цифр, например "004137". Ведущие нули значимы.

Код возвращается, когда модем поставил сообщение в очередь или провайдер принял его. Срок действия и число попыток ввода ограничивает ваше приложение. Стандартный текст сообщения предусматривает пять минут.

Системная SMS отправляется за счёт сервиса. Части SMS с указанием филиала расходуют его квоту. Для сервиса рассылки нужен подключённый аккаунт филиала. Для YCLIENTS GateBot ищет точное совпадение телефона в CRM филиала и отправляет сообщение по найденному ID клиента. Сервис рассылки и YCLIENTS не расходуют SMS филиала в GateBot.

Прочитать отзывы

Ответ GET /reviews — JSON-массив от новых отзывов к старым. У каждой записи есть id, branch_id, название филиала branch, имя автора author, оценка stars, текст message и время created в ISO 8601 UTC. Без оценки stars равно null. Без комментария message — пустая строка.

Ограничения и ошибки

Токен допускает заданное при создании число запросов за последние 60 секунд. Для одного телефона действует общий интервал между попытками в 60 секунд и до десяти попыток за час.

При ошибке ответ содержит JSON с полем error. HTTP 400 — неверные параметры, 401 — токен не принят, 403 — нет права, 404 — филиал, канал или клиент не найден, 409 — канал, квота или данные CRM не позволяют отправить сообщение.

При HTTP 429 заголовок Retry-After сообщает время ожидания в секундах. HTTP 503 означает недоступность доставки. При delivery_unknown сообщение могло уйти, поэтому не повторяйте отправку автоматически.
