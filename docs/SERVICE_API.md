# API GateBot

API версии 1 предназначен для серверов интеграций. Базовый путь — `/api/v1` на HTTPS-домене вашего GateBot. Для каждого запроса передайте заголовок `Authorization: Bearer <токен>`. Токен создаёт владелец сервиса в разделе **API GateBot**. Там же он выбирает разрешённые методы и лимит, видит счётчик и время последнего обращения, отзывает токен. Скопируйте значение при создании и сохраните на сервере интеграции. Браузер клиента не должен его получать.

| Метод | Путь | Право токена | Результат |
| --- | --- | --- | --- |
| GET | `/reviews` | `reviews` | Все отзывы, сначала новые |
| POST | `/codes/sms` | `system_sms` | Код через системный модем, без списания у филиала |
| POST | `/branches/{id}/codes/sms` | `branch_sms` | Код через модем. Части SMS учитываются в квоте указанного филиала |
| POST | `/branches/{id}/codes/chatpush` | `branch_chatpush` | Код через подключённый ChatPush по телефону, без списания SMS в GateBot |
| POST | `/branches/{id}/codes/yclients` | `branch_yclients` | Поиск полного телефона в CRM филиала и отправка через рассылку YCLIENTS единственному совпавшему клиенту по его ID, без списания SMS в GateBot |

Для методов филиала `{id}` — числовой ID филиала в GateBot. Право на метод охватывает все доступные этому сервису филиалы. Выпускайте отдельный токен для каждого доверенного серверного приложения. Например, сайту с отзывами достаточно права `reviews`.

## Получить код

Во всех четырёх POST-методах заголовок `Content-Type: application/json`. В теле один ключ `phone` с номером в строке. Например, в запросе на системную SMS:

```http
POST /api/v1/codes/sms
Authorization: Bearer <токен>
Content-Type: application/json

{"phone":"<номер с кодом страны>"}
```

Успешный ответ HTTP 200 содержит только JSON-строку с шестью цифрами, например `"004137"`. Сравнивайте код как строку, сохраняя ведущие нули. GateBot возвращает код после принятия команды очередью модема или сервисом рассылки. Поступление на телефон зависит от оператора и настроек сервиса филиала. Срок действия, число попыток, однократность и проверку введённого кода обеспечивает ваше приложение. При стандартном тексте сообщения задайте срок пять минут. Этот код предназначен только для вашей интеграции.

## Получить отзывы

`GET /api/v1/reviews` возвращает JSON-массив. У пустого списка ответ `[]`. Название филиала берётся из текущих настроек. Имя автора сохраняется при отправке. Для прежних отзывов используется имя из сохранившейся карточки, при его отсутствии — «Клиент». Время — ISO 8601 в UTC.

```json
[{"id":1,"branch_id":"12","branch":"Север","author":"Анна","stars":5,"message":"Удобно","created":"2026-11-21T10:00:00+00:00"}]
```

`stars` может быть `null` для текстового отзыва, `message` может быть пустой строкой для одной оценки. Выводите текстовые поля как обычный текст.

## Лимиты и ошибки

Скользящий лимит токена по умолчанию 30 запросов за 60 секунд, настройка от 1 до 600. Счётчик включает обращения с действующим токеном, в том числе отклонённые из-за прав или лимита. Для одного нормализованного телефона все API-токены и способы отправки вместе допускают одну попытку за 60 секунд и десять за час. При неопределённом исходе доставки автоматического повтора нет.

Ошибки передаются JSON-объектом с полем `error`. Даже при неопределённом результате доставки код в ответ не включается.

| HTTP | Причина |
| --- | --- |
| 400 | Неверный JSON или телефон |
| 401 | Токен отсутствует, неверен или отозван |
| 403 | У токена нет права на метод |
| 404 | Нет филиала, канала или совпадающего клиента YCLIENTS |
| 409 | Канал не подключён, совпадений в CRM несколько либо недостаточно квоты |
| 429 | Лимит токена или телефона. `Retry-After` указывает число секунд до следующей попытки |
| 503 | Отправка недоступна либо её результат неизвестен |

## Коды QR филиала и ворот

В **Интеграциях** при подключённом ChatPush доступна настройка **Подтверждение телефона по QR**. Один выбор действует для QR регистрации филиала и QR конкретных ворот. По умолчанию используется SMS. SMS-коды обоих QR расходуют квоту филиала. При выборе ChatPush код приходит сообщением в подключённый мессенджер. Без действующего подключения ChatPush используется SMS. Код для первичной регистрации самого филиала остаётся системным.
