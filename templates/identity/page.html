Два способа подключения YCLIENTS

Учётная запись YCLIENTS. При регистрации на сайте укажите ID филиала. Затем в «Интеграциях» войдите с логином и паролем пользователя YCLIENTS, у которого есть доступ к этому филиалу. После подключения здесь появятся его имя и контакты.

Приложение YCLIENTS Marketplace. Откройте карточку GateBot в маркетплейсе, нажмите «Подключить» и выберите филиал. При первой регистрации проверьте данные, подтвердите телефон по SMS и задайте пароль GateBot. Если у вас уже есть кабинет этого филиала, войдите с действующим паролем.

Для автоматических пропусков нужен доступ к записям всех сотрудников и телефонам клиентов в журнале записи. Для поиска ID и email нужен доступ к клиентской базе, а для отправки через YCLIENTS нужны права на рассылку. «Проверить доступ» покажет текущие права подключения.

Сообщения через ChatPush или YCLIENTS

В блоке «Сообщения клиентам» выберите способ доставки. ChatPush напрямую использует токен аккаунта и номер телефона. Рассылка YCLIENTS использует подключение филиала и ID его клиента; тип доставки определяется сервисом рассылки, настроенным в YCLIENTS.

Автоматический выбор использует подключённый ChatPush, иначе YCLIENTS. Клиент разрешает общий канал «Мессенджеры (сообщение от администратора)». Для гостя без ID YCLIENTS доступна прямая отправка через подключённый ChatPush. Сохранение настройки не отправляет пробных сообщений.
