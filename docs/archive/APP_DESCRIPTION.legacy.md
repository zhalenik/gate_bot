# GateBot — Система управления доступом на парковку

## О приложении

**GateBot** — комплексная система автоматизированного управления доступом на парковку для бизнеса с интеграцией YClients. Приложение автоматически предоставляет клиентам временный доступ на стоянку в день их записи на услугу, отправляя SMS-уведомления со ссылками для открытия ворот. Клиенты могут открывать ворота через удобный веб-интерфейс или Telegram-бота, а администраторы управляют системой через веб-панель управления.

## Основные возможности

### Для клиентов
- **Автоматическое получение доступа** — доступ предоставляется автоматически в день записи на услугу
- **SMS-уведомления** — получение ссылки для доступа на парковку в SMS-сообщении
- **Веб-интерфейс** — открытие ворот через веб-страницу с кнопками управления
- **Telegram-бот** — управление доступом прямо из мессенджера с удобной клавиатурой
- **Множественные филиалы** — поддержка работы с несколькими филиалами одновременно

### Для администраторов
- **Веб-панель управления** — полный контроль над пользователями и настройками системы
- **Управление пользователями** — создание, редактирование, блокировка и удаление пользователей
- **Управление филиалами** — настройка филиалов с индивидуальными параметрами (логотипы, кнопки управления)
- **Временные пропуски** — создание одноразовых пропусков для гостей
- **Логирование действий** — полный журнал всех операций с фильтрацией по типам событий
- **Экспорт данных** — выгрузка списка пользователей в CSV-формате
- **Система ролей** — разделение прав доступа между суперадминистраторами и администраторами филиалов

### Автоматизация
- **Планировщик задач** — автоматическая проверка записей в YClients и предоставление доступа
- **Интеграция с YClients** — синхронизация данных клиентов и записей
- **Управление сроками доступа** — автоматическая установка и отзыв доступа по расписанию
- **Очистка данных** — автоматическое удаление временных пользователей и истекших доступов

### Технические особенности
- **SIM800C интеграция** — открытие ворот через GSM-модуль с дозвоном на номер шлагбаума
- **Безопасность** — токенизированный доступ с проверкой сроков действия
- **Многопрофильность** — поддержка работы с несколькими филиалами одновременно
- **Вебхуки** — обработка событий от внешних систем (YClients)
- **Логирование** — детальное логирование всех операций для отладки и аудита

## Технологии

- **Backend**: Python, Flask
- **Telegram Bot**: python-telegram-bot
- **Интеграции**: YClients API, SIM800C GSM-модуль
- **Хранение данных**: JSON-файлы
- **Веб-интерфейс**: HTML, CSS, JavaScript

- Салонов красоты и парикмахерских
- Медицинских центров и клиник
- Автосервисов

## Часто задаваемые вопросы (FAQ)

### 1. Как клиент получает доступ на парковку?

Доступ предоставляется автоматически в день записи на услугу. Система проверяет записи в YClients и отправляет SMS-сообщение со ссылкой для открытия ворот. Клиент может перейти по ссылке и открыть ворота через веб-интерфейс или использовать Telegram-бота для управления доступом.

### 2. Что делать, если ссылка не работает или ворота не открываются?

Если ссылка не работает, это может означать, что срок действия доступа истек или доступ был отозван администратором. Проверьте, что вы используете актуальную ссылку из SMS-сообщения, полученного в день записи. Если проблема сохраняется, обратитесь к администратору филиала через кнопку "Администратор" в интерфейсе или Telegram-боте.

### 3. Как администратор может создать пользователя вручную?

Администратор может создать пользователя через веб-панель управления в разделе "Создать ссылку". Необходимо указать имя клиента, номер телефона, ID клиента в YClients (если есть) и выбрать филиал. Можно также установить срок действия доступа и сразу отправить ссылку клиенту через SMS.

### 4. Можно ли использовать систему для нескольких филиалов?

Да, система поддерживает работу с несколькими филиалами одновременно. Каждый филиал может иметь свои настройки: логотип, кнопки управления воротами, контакты администратора. Администраторы филиалов видят только пользователей своего филиала, а суперадминистраторы имеют доступ ко всем филиалам.

### 5. Как отключить SMS-уведомления?

Клиент может отписаться от рассылки, перейдя по специальной ссылке в SMS-сообщении или через страницу отписки на сайте. После отписки клиент не будет получать автоматические уведомления, но администратор может в любой момент включить рассылку обратно через панель управления.
